{# Fallback shell for the auth pages, so the blueprint stands on its own. The three auth templates all `{% extends "base.html" %}`. Akasha provides a rich one at app level and Flask searches the app's template folder before any blueprint's, so Akasha keeps exactly the page it always had — this file is never reached there. Chronos has no base.html, which meant every auth page it served raised TemplateNotFound: logging out of Chronos redirected to /timeline/login and got a 500, and /timeline/register and /timeline/change-password were dead the same way. A blueprint that ships routes and templates but depends on a template only one of its two hosts happens to define is not self-contained; this is the missing piece rather than a second copy of Akasha's. Deliberately plain, and deliberately not branded: it is whichever service you are logged out of. No header (there is nothing to navigate to yet) and no favicon, because the apps name theirs differently and a broken icon link is worse than none.
